## 固定范围与使用方式

```bash
# 只读描述：校验原冻结包并显示外置限额，不读取 auth.json
node --experimental-strip-types src/cli/positive-probe.ts
# 只读核验冻结 Node/SDK 与完整合并模型目录，不调用 Provider
node --experimental-strip-types src/cli/positive-probe.ts --verify-runtime
```

默认入口仅描述，真实执行必须另行获得授权，并同时提供 `--execute --authorize-real-provider`。本次未使用这两个参数。普通 `eval` / `archive` 不会自动进入此路径。

入口固定原 `positive` 计划、候选身份、两题顺序、repeat=1、judgeRepeat=2、runId/judgeSeed 和原来的匿名正反展示顺序：先 baseline 两题，再 P 两题，最后两对各两轮评委。上限为 **4 个被评会话 + 4 个评委会话 = 8 个会话**；工具循环中的每个 HTTP 请求都单独记账，8 个会话不等于 8 次请求。

被评仍为 `minimax-cn/MiniMax-M3.1-Flash`；评委仍为 `xiaomi-token-plan-cn/mimo-v2.6-flash`。禁止型号、端点、协议、上下文窗口或 reasoning 身份漂移。整批前后及逐会话核对模型配置文件哈希，防止 baseline/P 中途改变参数；不回退到近似型号。

原 `FREEZE.json` 锚点为 `0dc6b4a4dcafb51b862a8143ab5eb103c309712ad5adfc0ec05b4e621b10cea7`。入口验证全部 67 个原冻结负载，真实执行前再核验原 Node 身份、全部 15,138 条 SDK 清单及 PATH 实际指向的 SDK。SDK 内部符号链接按原清单原文核验，禁止指向包外。运行目录采用原子创建，已存在即拒绝，不覆盖、不恢复、不自动重跑。

## 外置执行参数

这是原冻结包外的新执行配置，不能称为原 CLI 缺省参数原样运行：

| 项目 | 本入口固定值 |
| --- | --- |
| 会话总上限 | 8，包括 subject 与 judge |
| 整批预算 | 1,000,000,000 nanoUSD，即 US$1 保守等价 |
| 每请求输出上限 | subject 4096；judge 1024，校验最终 HTTP wire 字段 |
| 自动重试、压缩、缓存预热 | 全部关闭，含 SDK 会话外预热 |
| 超时 | subject 480 秒；judge 300 秒，沿用原计划 |
| 工具与 skill | 原生 Pi 工具；禁自动发现；baseline 无 skill，P 仅显式目标包 |
| 网络和鉴权 | 模型及其工具进程禁止网络；父进程独占真实凭证并统一发送请求 |

SDK worker 被复制为独立 `.mts` 后在严格文件沙箱启动，无须扩大到读取整个仓库。每次会话运行实际文件访问探针；隐藏断言、真值、运行清单、账本及原始 HTTP 证据留在模型不可读写的控制目录。原生工具未重造。worker 只有占位凭证；父进程只支持所选 provider 的字面量 API key，不执行动态凭证命令。

本机系统 `/usr/bin/python3` 经 xcrun 启动时会尝试写默认系统临时缓存，严格沙箱原先拒绝该写入并产生警告。外置配置统一设置 `xcrun_db=<workspace>/.xcrun_db`，把原生缓存限制在本会话可写目录；baseline、P 与评委同参。已离线确认系统 Python 仍为 3.9.6、退出 0 且 stderr 为空；未扩大文件权限、替换 Python、过滤错误或修改冻结脚本。

## 请求前预留与费用累计

费用使用整数 nanoUSD，单一账本累计 subject 与 judge，独立于 SDK 的 `usage.cost`。截至 2026-11-06 的公开价格为：

| 模型 | 未缓存输入 US$/百万 token | 输出 US$/百万 token | 单请求最坏预留 US$ |
| --- | ---: | ---: | ---: |
| MiniMax-M3.1-Flash | 0.15 | 0.60 | 0.152457600 |
| mimo-v2.6-flash | 0.14 | 0.28 | 0.147087360 |

来源：[MiniMax 官方定价](https://www.minimax.io/blog/minimax-m31f)、[MiMo 官方 PAYGO 定价](https://mimo.mi.com/docs/en-US/price/pay-as-you-go)。

预留公式为 `模型上下文窗口 × 未缓存输入价 + 本次输出上限 × 输出价`。每次 HTTP 请求发送前锁定这笔最坏费用并持久化；剩余额度不足则拒绝发送，即使还有少量余额。拒绝并发请求、自动重定向、未经定价的服务端工具与非文本输入，并限制请求/响应体。成功后以原始 SSE 的最终输入、输出及缓存计数结算，缓存全部按未缓存输入价保守计算，再释放差额。Anthropic 流末更新的输入计数也必须纳入。

HTTP 失败、超时、中断、截断、模型身份不符、计数异常或缺失 usage 时，保留该请求**全部预留费用**并停止。账本先写临时文件、fsync、原子替换并 fsync 目录；无法持久化时停止网络并清理进程。硬停止仅取消本地后续工作，不能撤销已发请求；这部分已由预留覆盖。异常后不释放模糊费用，也不恢复旧账本续跑。

该限额是本入口按固定价表定义的保守美元等价，受固定模型上下文和输出契约约束。它不是账户级现金账单上限，不覆盖其他程序的用量。MiMo 当前端点是 Token Plan；其 SDK 成本 0 不代表免费，套餐现金分摊、剩余 Credits、地区计价和账户侧封顶仍未知。参见 [MiMo Token Plan](https://mimo.mi.com/docs/en-US/price/token-plan)。

## 异常与阳性判据

任一鉴权/权限/配额错误、HTTP/流异常、工具失败、输出为空、超时、预算不足或证据写入失败都会停止后续会话。保留失败事件、部分 SSE、原始输出和保守费用，剩余计划行明确为 `NOT_RUN`；失败空输出的断言为 null。

P 两题必须都满足：成功读取候选包、用 `/usr/bin/python3` 执行精确冻结脚本及对应模式、脚本 stdout 通过冻结断言且与最终 JSON 交付一致。只认可可核验的单次解释器调用、普通文件 stdin 或带引号的 here-document；复杂 shell 组合记为证据不足，不改原 skill。

baseline 断言失败是对照数据，不能因此提前中止。四个 subject 完成后须至少有一题检出植入差异，再进入匿名评委。评委保留每轮原始输出及判定；原始分数/置信度越界、标签和分差方向不符、逆向判定、无效 JSON 或正反不一致即停。只有完整 8 个会话、账本全部完成且无异常才允许阳性校验 PASS。它不触发主 60+4 任务，不归档候选，也不套用主实验的显著性结论。
