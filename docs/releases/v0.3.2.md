# v0.3.2：恢复原生 Pi 执行与增量证据持久化

日期：2026-11-07（Asia/Shanghai）。489 项离线验证及原生配置完整真实案例通过，独立证据复核通过；本文件随 v0.3.2 固化。

## 问题与行为变化

Host 曾额外施加低 token 上限、关闭评委思考、禁用 SDK 恢复，并把单样本失败传播成整批停止；事件与费用持久化还重复覆盖累计历史。本版本让 Host 回到环境和证据管理职责，Agent 使用官方 Pi 原生执行能力。

- 上下文与输出取已核验完整模型目录的原生额度；MiniMax 为 1,000,000 / 524,288，MiMo 为 1,048,576 / 131,072 token。不改模型、不改或升级 SDK。
- 保留 SDK 原生思考、重试、压缩、缓存预热与长度恢复；不新增修复 Agent、命令分类器或专用编排。
- 取消预算封顶、固定 8 会话硬限、默认时限及请求/响应字节限制。冻结实验矩阵仍按原方案执行，不将内部 HTTP 重试算作新增独立样本。
- 普通工具错误与 SDK 中间故障留作观察；最终样本失败或无效评委票仍计入分母并使整批保持 partial，继续其余独立计划项。Host 身份、隔离、IPC、持久化故障仍停批。
- 原始事件与费用变更增量追加 JSONL；失败派生摘要只在必要边界生成，兼容终态 JSON 只写一次，避免逐事件/逐请求重写完整历史。
- 评委接收完整匿名输出和全部匿名执行计数，移除额外字符采样。

## 保留范围

原 eval 是唯一编排，subject/judge 共用执行与费用记录。保留六项计分正确性修复：候选冻结身份、完整矩阵与缺失分母、访问隔离及激活取证、匿名成对评委及全部票、任务簇统计、阴性对照可比性。OS 隔离与凭证仅由 Host 持有的边界保持。

v1/v2 专用编排不恢复；历史评测、原冻结包和所有失败批次不覆盖、不拼接或选择性补跑。私有真值、隐藏断言、凭证和原始运行材料留在 `.local` / `runs`，不进入 Git。该版本固化评估器，不把两题链路验证当作 skill 有效性认证。
