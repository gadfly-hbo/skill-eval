# skill-eval v0.3.5

本版汇总 v0.3.3 复盘的四项修复。v0.3.4-ff1382f 是只在本机使用的候选版本。

- Qoder 默认流程移除直接启动候选门禁脚本的步骤及包装器，保留对候选规则的静态审阅，原样交付测评器报告。
- 增益不可判定或有效评判为零时报告「结论不足」。完整低增益仍可判「无效」，缺失配对保留计划分母。
- 人工盲审和正式评委共用评分载体。普通题使用对话，指定落盘题使用经哈希验证的 `deliverable.md`。快照缺失或哈希不符时标记无法校准。
- 开跑前展示各档的证据范围，列出冻结套件的独立计分题、计划计分对和会话数。使用手册与 `threshold` 明确任务级 Hoeffding 判定区间、描述性 Wilson 区间，以及两类单次会话默认不设超时。

GitHub Actions 在 macOS 运行类型检查和离线测试。验收范围为离线夹具、CLI 和本机技能发现。未运行真实测评，未调用真实 Provider。读取取证、归因及性能和存储继续观察。已有题集、运行与历史判定沿用各自冻结版本。
