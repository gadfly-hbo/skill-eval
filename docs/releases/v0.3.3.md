# v0.3.3 正式使用基线

2026-11-07（Asia/Shanghai）。将本版本固定用于日常 Skill 测评。测评器负责两件事：在同一口径下评分，以及找出有证据支持的候选问题，交给 OptraCall 修改和迭代。

## 正式使用

- 对照两侧使用同一测评器版本、模型、题集和评分口径。候选迭代复用同一冻结题集及执行配置。不同题集的结果分别报告。
- Qoder 引用正式结论和证据。确认需要修改 Skill 时，给出失败证据、修改位置、目标行为和验收用例，供用户转交 OptraCall。
- 执行失败、未运行或证据不足按运行记录报告。单个可疑判定保留原记录。运行期间保持冻结口径，测评器及题集问题留到独立维护周期集中复盘。
- 本机 Qoder 入口使用此版本的独立检出。候选暂存区、归档区、历史运行和 Pi 配置继续使用已有位置。

## 固化范围

- 沿用原 `eval` 入口与 Pi SDK。Host 负责隔离、采集和留痕，Agent 在授权环境中自主执行。
- `decision-review-v4` 对齐指定文件、首个非空状态行及判分证据。规则与盲评使用同一文件快照。报告分别列出标签冲突、配对分歧和被纠偏移除的胜出。
- v1/v2/v3 题集、原始运行及历史结论保留原口径。后续升级使用新版本。新旧版比较时保留各自版本和证据。

验收采用 `npm run check`、本机入口和 Qoder 技能发现的离线检查。v4 的真实评分表现留待正式使用中观察。
